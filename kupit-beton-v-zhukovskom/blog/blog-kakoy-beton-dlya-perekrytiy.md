# Какой бетон нужен для монолитных перекрытий

Монолитное перекрытие — несущий элемент, от прочности которого зависит безопасность всего дома. Ошибиться с материалом здесь нельзя. Бетон ниже нормативной марки оборачивается недостаточной несущей способностью, трещинами и со временем — аварийным состоянием конструкции. Разберём, какой бетон брать для монолитных перекрытий с учётом нормативов и практики строительства.

## Нормативные требования к бетону перекрытий

По СП 52-101-2003 «Бетонные и железобетонные конструкции без предварительного напряжения арматуры» минимальная марка бетона для монолитных железобетонных конструкций — **В20 (М250)**. Это абсолютный нижний предел, опускаться ниже которого недопустимо.

На деле нормативного минимума хватает не всегда:

- **В20 (М250)** — минимум по СП 52-101-2003, годится для хозпостроек, гаражей, нежилых зданий
- **В22,5 (М300)** — рекомендуется для жилых домов, коттеджей, многоэтажек
- **В25 (М350)** — для зданий с повышенными нагрузками, пролётами свыше 6 м, подземных этажей

Для жилого дома в Раменском районе стандартом служит **М300 (В22,5)** — такой выбор и нормативам отвечает, и даёт нужный запас прочности.

## Подвижность бетона при подаче насосом

При заливке монолитного перекрытия бетон обычно подают бетононасосом — так смесь удаётся ровно разложить по опалубке на высоте. Для работы с насосом бетон должен быть достаточно подвижным.

Подвижность оценивают осадкой стандартного конуса (ОК) и маркируют от П1 до П5:

- **П3** (ОК 10–15 см) — для бетонирования с минимальной дистанцией подачи, горизонтальные конструкции
- **П4** (ОК 16–20 см) — оптимальная подвижность при подаче насосом по горизонтали и вертикали
- **П5** (ОК более 20 см) — при сложной геометрии опалубки и плотном армировании

Стандарт для монолитного перекрытия с подачей насосом — **П4 (осадка конуса 16–20 см)**. Заказывая бетон, указывайте подвижность П4 — производитель добавит пластификатор в нужном объёме.

Важно: не поднимайте подвижность своими силами, доливая воду в миксер на объекте. Лишняя вода снижает прочность бетона и ломает водоцементное соотношение.

## Расчёт объёма бетона для перекрытия

Типовая толщина монолитного перекрытия в жилом строительстве — **200–220 мм**. Точное значение задаёт расчёт на нагрузки, но для пролётов 4–6 м принимают 200 мм, для 6–8 м — 220–250 мм.

**Формула расчёта:**

V = Площадь × Толщина

**Пример 1.** Перекрытие над первым этажом дома 8×10 м = 80 м², толщина 200 мм:

V = 80 м² × 0,20 м = **16 м³**

С поправкой на потери при заливке (3–5%) заказывайте **16,5–17 м³**.

**Пример 2.** Перекрытие 12×8 м = 96 м², толщина 220 мм:

V = 96 × 0,22 = 21,1 м³ → заказ **22 м³**

При расчёте вычитайте проёмы (лестничный пролёт, вентшахты и т. д.), если их площадь больше 1 м².

## Нагрузки на монолитное перекрытие

Перекрытие держит два вида нагрузок:

**Постоянные нагрузки** — собственный вес конструкции. Монолитная плита толщиной 200 мм из железобетона весит **500 кг/м²** (плотность железобетона 2500 кг/м³ × 0,2 м). Сюда прибавляется вес перегородок, стяжки пола и отделки — ещё **150–250 кг/м²**.

**Временные нагрузки** — люди, мебель, оборудование. По СП 20.13330.2017 для жилых зданий принимают **150 кг/м²** (1,5 кН/м²).

Итоговая расчётная нагрузка на монолитное перекрытие жилого дома — **800–900 кг/м²**. Бетон М300 с грамотным армированием держит такие нагрузки с многократным запасом.

## Армирование монолитного перекрытия

Монолитное перекрытие армируют в два слоя:
- **Нижняя сетка** (растянутая зона) — диаметр прутка 12–14 мм, шаг 150–200 мм
- **Верхняя сетка** (над опорами) — диаметр 10–12 мм, шаг 150–200 мм
- Защитный слой бетона снизу — 20–25 мм
- Защитный слой бетона сверху — 15–20 мм

Пруток берут рифлёный класса А400 (А-III). Гладкую арматуру А240 (А-I) для несущих перекрытий применять не советуют.

## Последовательность монолитных работ

1. **Устройство опалубки** — стойки с телескопическими домкратами через 1,0–1,2 м, балки, настил из фанеры 18–21 мм
2. **Армирование** — укладка нижней сетки на фиксаторы (защитный слой 25 мм), верхней сетки на распорках
3. **Установка закладных** — гильзы под коммуникации, анкера
4. **Бетонирование** — непрерывно, без холодных швов, послойно с вибрированием через каждые 30–40 см
5. **Уход за бетоном** — укрытие плёнкой, увлажнение в течение 7 суток
6. **Распалубка** — не раньше чем через **28 суток** после набора проектной прочности

Снимать опалубку с перекрытия раньше 28 суток категорически нельзя — даже при внешне «затвердевшем» виде бетон ещё не вышел на расчётную прочность.

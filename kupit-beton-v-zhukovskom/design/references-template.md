# Референсы для дизайна kupit-beton-v-zhukovskom

## Инструкция по заполнению

Для каждого сайта напиши:
1. Ссылку
2. Что именно нравится (конкретно: цвета, структура блоков, типографика, кнопки, hero, таблицы)
3. Что не нравится
4. Тип референса (конкурент / стиль / структура / UX / типографика)

Не обязательно нравиться весь сайт — можно указать один конкретный блок.

Скриншоты клади в `assets/references/` и указывай имя файла в поле «Скриншот».

# Цветовая палитра — Жуковский (референс vsemanipulyatory.ru)

Структура токенов и их применение по компонентам остаются как у донора (Щёлково).
Заменены ТОЛЬКО значения: бело-красная гамма → жёлто-синяя индустриальная (амбер + navy).

| Токен | HEX | Применение |

| --color-bg | #FFFFFF | Основной фон всех страниц |

## Ключевая связка (сигнатура референса)
**Амбер #FAB800 + Navy #12213A + белый.** Жёлтый — только на акцентах, navy — на тёмных блоках и тексте.

## Применение по компонентам (раскладка донора сохраняется)
- **Кнопка CTA (C2):** фон `--color-accent` (#FAB800), текст `--color-text-primary` (#12213A — тёмный, НЕ белый: на жёлтом белый нечитаем). Hover → `--color-accent-hover`.
- **Шапка (C1):** фон #FFFFFF; телефон #12213A жирный; кнопка «Позвонить» — accent-жёлтая с navy-текстом; нижняя граница `--color-border`; при scroll — тень.
- **Тёмные секции / футер:** фон `--color-bg-dark` navy, текст `--color-text-on-dark`, акценты жёлтые.
- **Sidebar каталога:** фон navy `--color-sidebar`, активный пункт — accent.
- **Цены в таблицах:** `--color-price` navy жирный; акционная перечёркнутая — `--color-sale`.
- **Чередование секций:** белый ↔ `--color-bg-alt` (кремовый).

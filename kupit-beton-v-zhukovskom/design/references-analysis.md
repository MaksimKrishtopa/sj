# Анализ референсов и ассетов

## 1. Анализ конкурентов

### Референс 1: Бетон-300 (beton300.ru)
Тип: конкурент + визуальный стиль
Стиль: чистый, белый фон, красный акцент

| Параметр | Что делают | Берём / не берём |
|---|---|---|
| Фон | Белый (#FFFFFF) | ✅ Берём — чистота и читаемость |
| Акцентный цвет | Красный (#E8372A) | ❓ На усмотрение клиента |
| Hero layout | Split-screen: текст слева + фото справа в карточке с radius | ✅ Берём структуру |
| Заголовок | Крупный, жирный (800), часть слов красным | ✅ Берём принцип выделения |
| Бейдж над H1 | Серый pill «БЕТОННЫЙ ЗАВОД · МОСКВА И МО» | ✅ Берём паттерн — геолокация над заголовком |
| CTA кнопка | Красная округлая, телефон как основной CTA | ✅ Телефон в кнопке — хорошо |
| Иконки-факты | 3 штуки под hero (2–4 часа / от 5м³ / ГОСТ) | ✅ Берём паттерн |
| Навигация | Горизонтальная, светлый фон, минимализм | ✅ Берём |
| Логотип | Красный квадрат + буква | ❌ Не копировать |
| Цена в фото | Карточка с ценой поверх фото «от 3950 ₽/м³» | ✅ Берём паттерн |

**Что нравится:** чистота, иерархия, читаемость, split-screen hero, бейдж-геолокация, цена прямо в картинке, факты под hero.
**Что не берём:** красный цвет (если у клиента другой), форму логотипа.

## 3. Синтез дизайн-направления (предварительный)

На основе просмотренных материалов прослеживается чёткое направление:

**Общий стиль:** Чистый промышленный. Белый фон + мощная типографика + один яркий акцент + реальные фото/видео.

**Аналог по ощущению:** Бетон-300 по чистоте и структуре, но с более современной типографикой и реальными фото вместо стоков.

**Визуальная ДНК (предварительно):**
1. Белый фон — основа всего
2. Один яркий акцент (красный / оранжевый — УТОЧНИТЬ у клиента)
3. Крупный жирный заголовок — данные и цифры на первом плане
4. Реальные фото строек и завода — доверие через реальность
5. Видеофон в hero — движение и масштаб
6. Split-screen hero: текст + цена слева, фото справа
7. Pill-бейдж над заголовком (геолокация, «завод в Жуковском»)
8. Факты-иконки под hero (3–4 штуки)
9. Индикатор «Сейчас ONLINE» или «Работаем до 22:00»
10. Фиксированные кнопки мессенджеров справа

**Анти-стиль:**
- Тёмный hero на всю страницу
- ЗАГЛАВНЫЕ во всех заголовках
- Стоковые фото строителей
- Перегруженная тёмная навигация
- Мультяшные иконки
- Градиентные кнопки

## Структура сайта (принята)
- `СТРУКТУРА-САЙТА_Вагон-дом-2.0.xlsx` (+ `.xmind`) — целевая структура (Дерево 399 узлов, аналитическая таблица, регионы, дорожная карта, вкладки матрицы).

# Контентный пакет для сайта — «Вагон дом 2.0» (батч 1)

## 1. Входные данные
### Проект
Новый филиал завода вагон-домов и модульных зданий (клон vagon-dom18.ru, новый бренд/контакты). Структура принята, прототипы готовы (`05_…`), SERP-требования — в `04_…`.
### Использованные материалы
Структура сайта и URL (`СТРУКТУРА-САЙТА_…`), прототипы страниц (`05_…` + JSON), SERP-анализ (`04_…` + JSON), профиль бизнеса (`00_…`). Семантика — у заказчика.
### Ограничения
Бренд, контакты, **цены**, реквизиты, кейсы-подтверждения, отзывы, точный регион филиала — не переданы. Всё это в тексте помечено `[Нужно уточнить у клиента: …]` и **не выдумывается**. Плейсхолдеры: `{БРЕНД}`, `+7 922 510 0555`, `{ГОРОД/РЕГИОН}`, «от `[цена]` ₽».

## 2. Краткий вывод
Готов контент по 5 страницам батча 1: **главная + жилые вагон-дома + бытовки + вагон-дом столовая + вахтовые посёлки под ключ** — по одному примеру на каждый ключевой шаблон (главная, категория, категория, спец-тип, услуга). Мета-теги, H-структура, тексты блоков (черновик/смысл), коммерческие блоки, FAQ, CTA, перелинковка, alt, микроразметка — по каждой. Критичные для финала данные (цены, бренд, контакты, кейсы) вынесены в «Нужно уточнить». Остальные страницы — следующими батчами (план в §7).

Формы заявки/расчёта/ТЗ (с загрузкой файла), калькулятор на категориях/услугах, фильтры каталога, таблицы, FAQ-аккордеон, хлебные крошки, карта (география/контакты).

Мета по шаблонам (Title 50–70, Description 130–160, один H1), H2-H3 как выше, микроразметка (Product/Offer, Service, FAQPage, LocalBusiness, ItemList, Breadcrumb), перелинковка, контроль дублей.

Фактчек всех `[Нужно уточнить]`; убрать воду; проверить уникальность категорий; подтвердить перенос кейсов.
### Вайб-кодингу
Генерировать по шаблонам из `05_…`; контент батча 1 — по этим URL; плейсхолдеры `{БРЕНД}`/`+7 922 510 0555`/`[цена]` заменяются централизованно.

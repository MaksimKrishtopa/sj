# Контентный пакет для сайта — Батч 3 (10 назначений-лендингов)

## 1. Входные данные

### Проект
«Вагон дом 2.0» — филиал завода вагон-домов и модульных зданий. Батч 3 покрывает 10 лендингов по назначению (тип помещения = отдельная посадочная) — самый коммерческий, «горячий» интент: пользователь ищет конкретное решение (душевая, офис, лаборатория и т.д.).

### Использованные материалы
- Мастер-мета `СТРУКТУРА+МЕТА_Вагон-дом-2.0.xlsx` (Title/Description/H1 + цена «от»).
- Фактурная база `facts.json` (vagon-dom18, тот же заказчик).
- Прототипы (`05_`), UX (`07_`), дизайн (`08_`), батч 2 (`09_`) — единый стиль тел.

### Ограничения
- Бренд/телефон — `{БРЕНД}`/`+7 922 510 0555`.
- Комплектации по каждому назначению даны как типовые (из практики отрасли и подсказок в мете); точный состав опций конкретного филиала → `[Нужно уточнить у клиента]`.
- Факты (опыт, ГОСТ, гарантия, сроки, доставка) — из `facts.json`, едины для всех.

## 2. Краткий вывод
Готовы 10 тел лендингов по назначению с уникальным AI-оптимизированным контентом. Каждый: прямой ответ «что это и для чего», комплектация/характеристики таблицей, модификации, цена «от» с логикой ценообразования, преимущества завода, FAQ+FAQPage, CTA, перелинковка (назначение ↔ каталог ↔ смежные назначения ↔ доверие), schema Product/BreadcrumbList/FAQPage. 8 из 10 имеют реальную цену «от»; для «кухни» цена «по запросу» (плюс разведён дубль со «столовой»).

## 5. Общие рекомендации по контенту
Единый шаблон лендинга по назначению: прямой ответ «что это и для чего» → комплектация/характеристики таблицей → модификации → цена «от» + логика ценообразования → преимущества завода (единый блок фактов) → как заказать (6 шагов) → FAQ. Тон экспертный, без воды. Обязательно разведение близких назначений в тексте и FAQ (душевая≠санузел, кухня≠столовая, слесарная≠инструментальная≠сварочный, офис≠прорабская≠кабинет≠конференц-зал≠штаб) — это снимает каннибализацию и усиливает релевантность. Повторяемые факты (опыт, ГОСТ, гарантия, сроки, доставка) единообразны. Бренд/телефон — плейсхолдеры.

## 6. Контентные риски
| Риск | Где | Что сделать |
|---|---|---|
| Выдуманная комплектация | все лендинги | Держать `[Уточнить]`, не сочинять точный состав |
| Каннибализация близких назначений | душевая/санузел, кухня/столовая, мастерские | Разведение в тексте и FAQ + перекрёстные ссылки |
| Цена «по запросу» без ориентира | /kuhnya/ | Запросить цену «от» у клиента |
| Требования к спецпомещениям | лаборатория, медпункт, сварочный | Не заявлять сертификацию/лицензии без данных |

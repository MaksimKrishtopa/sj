# Контентный пакет для сайта — Батч 4 (10 назначений-лендингов)

## 1. Входные данные

### Проект
«Вагон дом 2.0». Батч 4 закрывает оставшиеся лендинги по назначению — санитарно-бытовые (санузлы, бани, сауны, раздевалки) и административно-технические (инструментальные мастерские, операторские, прорабские, конференц-залы, штаб, склады). Вместе с батчами 1 и 3 это завершает декомпозицию «каждое назначение = отдельная посадочная».

### Использованные материалы
Мастер-мета (Title/Description/H1 + цена «от»), `facts.json`, единый шаблон лендинга назначения из батча 3, прототипы/UX/дизайн.

### Ограничения
- Бренд/телефон — `{БРЕНД}`/`+7 922 510 0555`.
- 5 из 10 назначений — цена «по запросу» (раздевалки, операторские, прорабские, штаб, склады) → нужна цена «от» от клиента.
- Комплектации — типовые; точный состав → `[Нужно уточнить у клиента]`.
- Факты — из `facts.json`, едины.

## 2. Краткий вывод
Готовы 10 тел лендингов по назначению по единому шаблону: прямой ответ «что это и для чего» → комплектация → модификации → цена «от»/по запросу → преимущества → как заказать → FAQ+FAQPage → перелинковка. Особый акцент — разведение близких назначений (санузел≠душевая, баня≠сауна, инструментальная≠слесарная, прорабская≠офис≠штаб≠конференц-зал), чтобы исключить каннибализацию. 5 страниц с реальной ценой, 5 — «по запросу» (помечены для клиента).

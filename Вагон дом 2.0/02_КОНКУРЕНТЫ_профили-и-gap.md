## Предварительный GAP: что есть у конкурентов, чего нет (или слабо) у нас

Наш сайт сейчас: вагон-дома (68 товаров) + модульные здания (+офисы, столовая) + в наличии, доставка, оплата, характеристики, сертификаты, о компании, контакты + 155 кейсов «наши работы». Нет: региональных посадочных, посадочных по вместимости, раздела модульных зданий по назначению, вахтовых посёлков как воронки, инфо-блога, отзывов/видео, аренды/трейд-ин.

**Кандидаты в гибрид (по убыванию приоритета):**

1. **Региональные посадочные** `вагон-дома-{город}` — есть у lider (~40) и vagonoff (~160). Сильнейший SEO-рычаг. → набор приоритетных городов под наш филиал.
2. **Модульные здания по назначению** (школы, детсады, ФАП/медпункты, общежития, столовые, КПП, операторные, АБК, ангары/склады, спорт, ДК) — глубоко у vagondoma. У нас только общий раздел.
3. **Вахтовые посёлки / городки** как отдельная воронка (кратко/средне/долгосрочные, обустройство месторождений) — vagondoma, savaservis, vagonoff, prosps.
4. **Посадочные по вместимости**: вагон-дома на 2/4/6/8 чел., столовые на 20–70 чел. — lider, vagonoff.
5. **Типы вагон-домов как категории** (жилые, бытовки, офисы/прорабские, столовые/кухни, душевые, санузлы, сушилки, прачечные, сауны/бани, мастерские слесарные/инструментальные, лаборатории, медпункты, КПП, склады, пекарни, культбудка) — у нас есть как товары, у конкурентов оформлены категориями/посадочными.
6. **Конструкция как разрез**: на шасси / на санях / на раме / на колёсах — vagondoma, lider.
7. **Инфо-блог / статьи** (экспертные материалы) — vagondoma(49), savaservis(68), lider, vagonoff.
8. **Отзывы, Видео, FAQ, Тендеры** — vagonoff.
9. **Аренда и Trade-in** — savaservis.
10. **Со склада / в наличии** — есть у нас (`/v-nalichii/`), усилить (у savaservis, vagonoff отдельно).
11. **Каркасно-панельные / быстровозводимые из сэндвич-панелей, металлоконструкции, каркасно-тентовые** — savaservis, prosps, vagondoma (смежные направления, обсудить с заказчиком по приоритету).
12. **Смежные линейки** (ДЭС/дизельные станции — lider; резервуары — lider) — вероятно вне профиля, на решение заказчика.

Дальше: по команде «всё» собираю единую гибридную структуру (наша база + отобранные gap-разделы) с пометкой источника по каждому блоку, затем — на согласование заказчику.

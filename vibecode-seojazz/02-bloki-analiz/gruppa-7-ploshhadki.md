# Этап 2Б. Разбор блоков — Группа 7: продвижение на площадках

> Страницы группы: хаб `/prodvizhenie-na-ploshhadkah/` + Авито под ключ, геомаркетинг, Яндекс Карты, 2ГИС, Яндекс Бизнес, Google Карты.
> Тип страницы в топе: **посадочная услуги под площадку/канал**. Интент: коммерческий (Авито, геосервисы под ключ) / инфо-выдача (общие «продвижение на картах/бизнес» — блоги, официальные сервисы).
> Данные: полностью разобраны rocketdata.ru (геосервисы/карты — SaaS-платформа) и pixelplus.ru/marketplace/avito (Авито под ключ — агентство). Профильные конкуренты: rocketdata, pixelplus/marketplace, callibri, официальные (business.yandex, реклама.2gis).
> Обновлено: 2026-07-06.

---

## 1. Внутри группы — два разных подтипа шаблона

### Подтип A. Геосервисы / карты / 2ГИС / Я.Бизнес / геомаркетинг (эталон — RocketData)

Модель — **управление онлайн-присутствием в геосервисах** (часто SaaS-платформа + сопровождение).

Блоки: hero «больше клиентов из офлайн через геосервисы» → «для кого» (сети/филиалы, маркетинг, клиентский сервис) → **«для каких задач»** (рост локальной выдачи, конверсии, рейтинга/отзывов, управление данными и репутацией, аналитика) → «как помогаем бизнесу» (6 шагов: данные/отзывы → трафик из карт → конверсия → генерация отзывов → репутация → аналитика) → **путь клиента** (заявка → демо-встреча → старт → сопровождение 2 менеджерами 24/7) → преимущества (100+ площадок, официальная интеграция с 2ГИС, AI-функции, крупнейшая база 19000 компаний) → **отзывы клиентов-сетей** → **лид-магнит: бесплатный отчёт/аудит присутствия** (что в данных, заполнение профилей, точки на картах) → формы demo.

### Подтип B. Авито / маркетплейсы (эталон — Pixelplus Авито)

Модель — **агентское ведение под ключ** с оплатой по объёму.

Блоки: hero «Продвижение бизнеса на Авито» + оффер → услуги (продвижение / упаковка профиля / консультация) → **тарифы 3 по объёму** (Старт 32 000 ₽ до 500 объявлений, Профи 49 000 ₽ до 3000, Максимум 68 500 ₽ до 10 000) с детальным составом → **этапы (9): бриф/анализ → договор → стратегия/дорожная карта → запуск (профиль, обложки, тексты, автозагрузка) → ведение + CRM + чат-бот → оптимизация/A-B → отчётность → результаты → масштабирование** → команда (спецы по маркетплейсам) → «почему мы» + счётчики → **кейсы с метриками** (оборот 4,5 млн на 2-й мес, ДРР 3,15%, +продажи) → бриф-документ на скачивание → формы.

## 3. Прайсы

- **Авито (Pixelplus):** Старт 32 000 ₽, Профи 49 000 ₽, Максимум 68 500 ₽ — **тариф зависит от объёма объявлений/товаров** и набора работ (упаковка, инфографика, бот, отзывы). Без НДС.
- **Геосервисы (RocketData):** платформенная/подписочная модель + сопровождение; цена индивидуальна после демо (зависит от числа локаций 1-5 / 6-9 / 10-100 / 100+).

## 4. Кейсы

- Метрики под канал: для Авито/маркетплейсов — **оборот, ДРР, число заказов, CPL, конверсия** (Pixelplus: оборот 4,5 млн на 2-й месяц, ДРР 3,15%); для геосервисов — рост локальной выдачи, рейтинг, отзывы, целевые действия, пешеходный трафик.

## 5. Вопрос-ответ (FAQ)

- На эталонах явного FAQ мало. **Рекомендация: добавить FAQ** (что входит, сроки, оплата, работа с блокировками/модерацией Авито, гео-отзывы) — усилит AI-выдачу и конверсию.

## 6. Калькуляторы и формы

- **Гео:** форма-квиз (сайт + количество филиалов) + **бесплатный отчёт о присутствии в геосервисах** (сильнейший лид-магнит ниши).
- **Авито:** форма + **бриф-документ на скачивание** (Word) + консультация.

## 8. Слабые места конкурентов и где обходим (угол SEO Jazz)

- **Каждый канал продают в отрыве от сайта.** Наш угол — **омниканальный охват: сайт (SEO) + GEO/AI + Карты/2ГИС + Авито** как единая система привлечения заявок. Ни у кого нет связки «сайт + нейросети + площадки».
- **Метрики в заявках/выручке** — наш нарратив; для площадок это ложится напрямую (звонки/заявки/заказы).
- **Нет FAQ и GEO/AI-блока** — добавляем.
- У SEO Jazz уже есть страницы `/prodvizhenie-na-avito-pod-kljuch/` и `/geomarketing/` — усиливаем их по этим шаблонам, а карты/2ГИС/Я.Бизнес — по гео-подтипу.

## 9. Требования к нашим страницам площадок (итог)

Два подшаблона:
- **Гео (Карты/2ГИС/Я.Бизнес/геомаркетинг):** hero → для кого/задачи → что входит → как помогаем (6 шагов) → путь клиента → преимущества (площадки/интеграции/AI) → отзывы сетей → **лид-магнит «бесплатный аудит присутствия»** → форма-квиз + **FAQ и GEO/AI-блок (наши)**.
- **Авито/маркетплейсы:** hero → услуги → **тарифы по объёму (3)** → этапы (9) → команда → почему мы+счётчики → **кейсы (оборот/ДРР)** → бриф-документ → форма + **FAQ (наш)**.
Общий угол — омниканальность (сайт+SEO+GEO+площадки) и метрики в заявках/выручке.

# Этап 2Б. Разбор блоков — Группа 5: SEO по типу сайта

> Страницы группы: хаб `/seo-po-tipu-sajta/` + интернет-магазины, лендинги, корпоративные, каталоги, сайты услуг, визитки, информационные, маркетплейсы, агрегаторы, B2B, одностраничники, блоги/медиа, форумы, доски объявлений, SaaS.
> Тип страницы в топе: **посадочная услуги под тип сайта** (шаблон, размножается по типам). Интент: коммерческий (магазин/корпоративный/каталог/агрегатор/B2B) / инфо-выдача (лендинг, одностраничник, маркетплейс-селлеры, форум).
> Данные: полностью разобран lead.media/prodvizhenie-korporativnyh-sajtov. Профильные конкуренты: lead.media, kokoc/otraslevye-resheniya, grampus-studio, webtaktika, cinar, demis. (webtaktika отдал JS-пустышку — добирается через браузер.)

## 1. Блочный алгоритм страницы «тип сайта»

По сути — **универсальный шаблон услуги, но весь контент заточен под конкретный тип сайта** (для корпоративного — B2B/ЛПР/E-E-A-T; для магазина — категории/карточки/фильтры; для каталога — большой ассортимент; для лендинга — одностраничник).

1. **Hero:** H1 «SEO-продвижение <тип сайта> в Москве» + подзаголовок с болью типа («корпоративный сайт — визитка, но без трафика бесполезен») + метрики (×3 заявок, срок, N проектов, цена «от …₽») + 2 CTA (бесплатный аудит + тарифы).
2. **Метрики «в цифрах»** (проектов, средний рост заявок, % продлений, оценка).
3. **«N причин, почему <тип сайта> не привлекает клиентов»** — 4 проблемы, специфичные для типа (для корп.: шаблонный контент без экспертизы, нет B2B-семантики, не конвертит B2B, устаревший дизайн).
4. **«6 направлений SEO для <тип сайта>»** — под специфику типа (для корп.: B2B-семантика, экспертный контент/E-E-A-T, раздел «Для партнёров», техника, ссылки для B2B, репутация/PR).
5. **Сравнительная таблица** «мы / среднее агентство / фрилансер» (параметры под тип).
6. **Кейсы «А→B»** с метриками типа (для корп.: B2B-заявки ×4, средний чек +75%, стоимость заявки −68%).
7. **Этапы-таймлайн** (Дни 1–5 / 5–14 / … / 60+).
8. **Тарифы (3)** — Стандарт/Бизнес/Enterprise (55/95/170к), состав по нарастающей (число запросов, страниц, статей, PR).
9. **Команда + сертификаты/награды.**
10. **«Подтверждено данными»** — внешние источники (HubSpot, Serpstat, Ahrefs, Backlinko).
11. **Гарантии в договоре** — KPI по заявкам (не позиции), NDA, «всё остаётся при расторжении», первые результаты за 14 дней.
12. **Отзывы** (ЛПР с ролями) + карточка эксперта-руководителя SEO.
13. **FAQ (8), answer-first** — под тип («чем B2B-SEO отличается», «нужен ли блог», «сроки», «ROI», «Enterprise/мультиязык»).
14. **Связанные услуги + перелинковка на другие типы сайтов** (лендинги, каталоги, магазины…).
15. **Финальный CTA — бесплатный аудит** («ответим за 15 минут, покажем прогноз заявок»).

> Примечание: это тот же каркас, что у lead.media на GEO-странице (Группа 2) — агентство использует **единый мастер-шаблон**, меняя контент под тип/платформу/нишу. Для нас вывод: делаем **один сильный мастер-шаблон услуги** и специализируем его контентом под тип.

## 3. Прайсы

- **Lead.Media (корпоративные):** Стандарт 55 000 ₽ (до 200 запросов), Бизнес 95 000 ₽ (до 500 + PR), Enterprise 170 000 ₽ (1000+, мультирегион). 3 тарифа лесенкой, состав по нарастающей.
- Цена «от …₽» вынесена в hero и title.

## 4. Кейсы

- «А→B» с метриками, специфичными для типа: для корпоративного — **B2B-заявки/мес, средний чек, стоимость заявки, позиции ТОП-10**; для магазина ожидаемо — заказы/выручка/трафик. По отраслям (производство, IT, логистика).

## 5. Вопрос-ответ (FAQ)

- 8 answer-first вопросов под тип: стоимость, «чем B2B-SEO отличается», нужен ли блог, сроки, ROI, Enterprise/мультиязык, что входит в месяц. Отлично тянется в AI-выдачу.

## 6. Калькуляторы и формы

- Калькулятора нет; **бесплатный аудит** как главный крючок + мультиканальные формы + «ответим за 15 минут». (У некоторых конкурентов группы, напр. yudena, — квиз-калькулятор; можно взять оттуда.)

## 7. Типовые фразы

«<тип сайта> — <боль>, но без трафика бесполезен», «B2B-семантика / запросы ЛПР», «E-E-A-T и экспертный контент», «раздел для партнёров / запрос КП онлайн», «рост B2B-заявок ×3 за 4 месяца», «KPI по заявкам, а не позиции», «стоимость заявки ниже контекста в 3–5 раз».

## 8. Слабые места конкурентов и где обходим (угол SEO Jazz)

- **Нет GEO/AI-блока** — добавляем.
- **Единый мастер-шаблон** — берём приём себе: один сильный каркас услуги, специализируемый контентом под тип/CMS/нишу/регион → быстрая и консистентная генерация 100+ страниц под вайб-код.
- **Метрики в заявках/выручке** lead.media уже делает; наш нарратив + реальные кейсы усиливают.
- **Перелинковка между типами** сильная — у нас можно связать типы × ниши × CMS × регионы в единую матрицу (как у yudena в Группе 4).
- Для инфо-выдачевых типов (лендинг, одностраничник, форум, маркетплейс-селлеры) — гибрид «экспертный гайд + блок услуги + FAQ», не чистый лендинг.

---

## 9. Требования к нашим страницам «тип сайта» (итог)

Мастер-шаблон услуги, специализируемый под тип: hero (боль типа + метрики + цена «от» + 2 CTA) → метрики → «причины, почему <тип> не привлекает» → 6 направлений под тип → сравнительная таблица → кейсы «А→B» с метриками типа → этапы-таймлайн → тарифы (3) → команда+сертификаты → «подтверждено данными» → гарантии по KPI-заявкам (в договоре) → отзывы+эксперт → **FAQ 8 answer-first + GEO/AI-блок (наш)** → перелинковка на другие типы → CTA-аудит. Контент (боли, направления, семантика, кейс-метрики, FAQ) — **уникальный под каждый тип**. Для инфо-выдачевых типов — гибрид гайд+услуга.

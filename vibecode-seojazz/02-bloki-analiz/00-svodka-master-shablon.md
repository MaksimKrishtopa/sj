# Сводка Этапа 2Б — мастер-шаблон и матрица блоков (все 7 групп)

> Синтез блочных моделей 7 групп в единую систему для вайб-кода: универсальное ядро + уникальные блоки по типам + сквозные блоки-обгона + матрица перелинковки + переиспользуемые компоненты.
> Источник — файлы `gruppa-1…7`. Обновлено: 2026-07-06.

Группы: **1** форматы услуг · **2** GEO/AI · **3** отраслевые ниши · **4** CMS · **5** типы сайтов · **6** создание сайтов · **7** площадки.

---

## 1. Универсальный мастер-шаблон (ядро, общее для всех коммерческих страниц)

Порядок блоков-«скелет», от которого наследуются все типы:

1. **Hero** — H1 под интент + оффер-подзаголовок (боль/выгода) + метрики (×N, срок, цена «от») + 1–2 CTA (заказать / бесплатный аудит).
2. **УТП-триплет / метрики** — 3 плашки сути услуги.
3. **Проблемный блок** — «почему <объект> не работает / N причин» (у GEO — «почему не цитирует», у CMS — тех-проблемы движка, у типов — почему тип не привлекает).
4. **Кому подходит / не подходит** (честный дисквалификатор).
5. **Что входит / направления работ** — детально, с числами-пруфами.
6. **Как строится работа / этапы** — таймлайн или нумерованные шаги.
7. **Прайс** — тарифы или «от …₽» + срок (модель зависит от группы, см. §5).
8. **Кейсы «А→B»** — с метриками, релевантными типу.
9. **Доверие** — команда + эксперт, счётчики, награды/сертификаты, отзывы.
10. **Гарантии** — финансовые/KPI в договоре.
11. **FAQ** — answer-first, под AI-выдачу.
12. **Формы + лид-магнит** (бесплатный аудит / бриф / чек-листы), мультиканал.
13. **Перелинковка** — на смежные страницы (см. §6).

## 3. Уникальные блоки по группам (что добавляем поверх ядра)

- **Г2 GEO/AI:** метрики AI-рынка; факторы ранжирования нейросети (%-веса); citation rate в кейсах; «подтверждено данными» (Similarweb/Princeton/Ahrefs); виджет «рейтинг брендов по мнению нейросетей»; лид-магнит «проверка цитируемости».
- **Г3 ниши:** особенности ниши + E-E-A-T/YMYL (авторы-эксперты, сертификаты); локальное SEO + каталоги; кейс «точка А→B» в деньгах; облегчённый вариант для низкочастотных ниш (инфо-выдача).
- **Г4 CMS:** контент под сущности движка (Views/инфоблоки/таксономии); квиз-калькулятор; для WordPress/Tilda — гибрид «гайд + услуга».
- **Г5 типы сайтов:** направления и семантика под тип (B2B/ЛПР для корп; категории/карточки для магазина); единый мастер-шаблон, специализируемый контентом.
- **Г6 создание сайтов:** экспертиза «полезны когда / знаем как»; портфолио; этапы разработки (8, вкл. интеграции/тестирование); прайс «от …₽ + срок + поддержка/час»; наш блок «сайт сразу под SEO/GEO».
- **Г7 площадки:** гео-подтип (управление присутствием, отзывы/рейтинг, бесплатный аудит присутствия); Авито-подтип (тарифы по объёму, этапы 9, бриф-документ).

## 4. Сквозные блоки-обгона SEO Jazz (добавляем на ВСЕ группы)

1. **GEO/AI-блок** — есть только у нас (широкий кластер платформ); конкуренты в лучшем случае строчкой.
2. **FAQ answer-first** — у многих групп (ниши, площадки, создание) его нет; двойная польза (возражения + AI-выдача).
3. **Метрики в заявках/выручке** («точка А→B в деньгах») вместо позиций/трафика — сквозной нарратив бренда.
4. **Финансовая гарантия по KPI-заявкам** — сильнее «мягких» гарантий рынка.
5. **Единая матрица перелинковки** (см. §6) — глубже, чем у любого конкурента.
6. **Реальные кейсы-пруфы** на каждой нишевой/типовой странице.

## 6. Единая матрица перелинковки (ключевой SEO-приём)

Связываем кластеры перекрёстно (у yudena/lead.media частично; у нас — полностью):

**услуга × CMS × тип сайта × отрасль/ниша × регион × площадка**

Пример для страницы: со страницы услуги → на «эту услугу для интернет-магазина» → «…на Битрикс» → «…для стоматологии» → «…в Москве» → «+ карты/Авито». Каждая страница = узел графа с блоком «связанные решения» (карточки с ценой «от»). Это даёт максимум точек входа и вес приоритетным страницам.

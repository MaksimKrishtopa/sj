## 1. Блочный алгоритм GEO-страницы (отличается от обычной услуги)

Порядок у лидеров ниши (эталон — lead.media):

1. **Hero:** H1 «Продвижение в <Нейросеть> в Москве» + провокационный подзаголовок-вопрос («когда спрашивают про вашу нишу — он цитирует вас?») + 2 CTA («Проверить видимость бесплатно» + «Смотреть тарифы»). Плашка траста в строке (10 лет / 200+ проектов / гарантии в договоре).
2. **Метрики рынка (счётчики):** аудитория нейросети, рост AI-трафика, «3–4 источника в ответе», «2–4 недели до первых цитирований». Отдельный блок «в цифрах» (запросы/мес, рост реф-трафика, рост цитируемости).
3. **Проблемный блок «почему теряете трафик / 5 причин»:** конкурентов цитируют, а вас нет; контент не структурирован под извлечение; низкий Domain Authority; нет свежего контента; нет Schema.org. С объяснением **факторов ранжирования в нейросети** (citation frequency 35%, DA 15%, schema 10%).
4. **Направления работ (6 шт.):** аудит цитируемости → контент под RAG → citation building → усиление DA/E-E-A-T → техническая GEO (Schema) → мониторинг и итерации.
5. **Сравнительная таблица** «мы vs обычное SEO-агентство vs без GEO» (рост mention rate, мониторинг, промпт-аудит, работа с entities).
6. **Кейсы с AI-метриками:** citation rate 0%→18–26%, переходы из нейросети, заявки из AI-канала, доход ×8 — по нишам.
7. **Этапы с таймлайном** (Дни 1–5 / 5–15 / 15–40 / 45+), у каждого измеримый результат.
8. **Тарифы (3 пакета):** Мониторинг / Рост / Лидер — с составом и ценой «от …₽/мес».
9. **Команда** (фото, роли; выделен «руководитель GEO/AI-направления»).
10. **Сертификаты, партнёрства, награды.**
11. **«Подтверждено данными»** — цитаты внешних исследований со ссылками (Similarweb, Princeton GEO Study, Ahrefs). Уникальный для ниши E-E-A-T-блок.
12. **Гарантии — измеримые, в договоре:** целевой citation rate, KPI, «не достигли — продлеваем бесплатно», «все материалы остаются у вас».
13. **Отзывы** (с ролями ЛПР: CEO SaaS, директор по продажам…).
14. **FAQ — очень большой (10–13 вопросов), answer-first** — заточен под извлечение самими нейросетями (что такое, как выбирает источники, сколько стоит, сроки, чем отличается от ChatGPT, локальный бизнес, типы контента…).
15. **Связанные услуги GEO** (перелинковка на другие платформы: ChatGPT/Gemini/Нейро + SEO + SERM + контент-маркетинг).
16. **Финальный CTA — бесплатная проверка цитируемости** («проверим ответы по 10 запросам вашей ниши»).

Особый блок у **pixelplus**: интерактивный виджет **«Лучшие бренды в нишах по мнению нейросетей»** (рейтинги OZON/WB, клиник, застройщиков с %) — сильный траст + вовлечение.

## 5. Вопрос-ответ (FAQ)

## 9. Требования к нашим GEO-страницам (итог)

Единый шаблон под каждую нейросеть (размножается по платформам): hero-вопрос + 2 CTA (проверка видимости / тарифы) → метрики рынка AI → «почему вас не цитирует» + факторы (%-веса) → 6 направлений работ → сравнительная таблица → кейсы с citation rate → этапы-таймлайн → тарифы (3) → «подтверждено данными» (внешние источники) → команда + GEO-эксперт → сертификаты/награды → гарантии по citation rate (в договоре) → отзывы ЛПР → **большой answer-first FAQ (10+)** → связанные GEO-услуги → финальный CTA «бесплатная проверка цитируемости». Плюс наш блок-обгон: виджет AI-рейтинга брендов и связка AI-канала с заявками. Вся страница строится по AI-first принципам (это и есть предмет услуги).

# Прототип страницы — Группа 5: SEO по типу сайта

> Эталонный прототип под страницу типа сайта. Размножается по типам (интернет-магазин, лендинг, корпоративный, каталог, услуги, визитка, маркетплейс, агрегатор, B2B, блог/медиа, форум, доска, SaaS). Рабочий пример — `/prodvizhenie-internet-magazinov/`.
> Это тот же **мастер-шаблон услуги**, специализируемый контентом под тип (см. gruppa-5). Вход — `02-bloki-analiz/gruppa-5-tipy-sajtov.md`.
> Обновлено: 2026-07-06.

- **Тип страницы:** посадочная услуги под тип сайта
- **Интент:** коммерческий (магазин/корп/каталог/агрегатор/B2B) / инфо (лендинг/одностраничник/форум/маркетплейс-селлеры)
- **Конверсионная цель:** заявка / бесплатный аудит
- **Первый экран:** боль типа + метрики + цена «от» + 2 CTA

---

## Структура блоков

### 1. Hero `[обязательный]`
- **Смысл:** H1 «SEO-продвижение <тип сайта>» + подзаголовок-боль типа («магазин без трафика — просто витрина»); метрики (×N, срок, N проектов, цена «от»); 2 CTA (аудит / тарифы). `[данные: цена/срок]`
- **SEO-задача:** ключ типа в H1/1-м абзаце.

### 2. Метрики «в цифрах» `[обязательный]`
- **Смысл:** проектов, средний рост заявок, % продлений, оценка. `[данные: счётчики]`

### 3. «N причин, почему <тип> не привлекает клиентов» `[обязательный]`
- **Задача:** сформировать потребность, специфично под тип.
- **Смысл:** для магазина — слабые карточки/фильтры/категории/дубли; для корп — нет B2B-семантики/шаблонный контент; для каталога — структура/фильтры.

### 4. «6 направлений SEO для <тип>» `[обязательный]`
- **Смысл:** под специфику типа (магазин: семантика категорий, карточки, фильтры, коммерческие факторы, ссылки, аналитика).

### 5. Сравнительная таблица `[желательный]`
- **Смысл:** «мы / среднее агентство / фрилансер» по параметрам типа.
- **Функционал:** таблица.

### 6. Кейсы «А→B» с метриками типа `[обязательный]`
- **Смысл:** для магазина — заказы/выручка/трафик/ДРР; для корп — B2B-заявки/средний чек. `[данные: наши кейсы под тип]`

### 7. Этапы-таймлайн `[обязательный]`
- **Смысл:** Дни 1–5 / 5–14 / … / 60+.

### 8. Тарифы (3) `[обязательный]`
- **Смысл:** Стандарт/Бизнес/Enterprise, состав + «от …₽». `[данные: суммы]`

### 9. Команда + сертификаты `[обязательный]`
- **Смысл:** эксперт + партнёрства/награды. `[данные]`

### 10. «Подтверждено данными» `[желательный — E-E-A-T]`
- **Смысл:** внешние источники (HubSpot/Ahrefs/Backlinko) с цифрами по типу. `[данные: ссылки]`

### 11. Гарантии по KPI-заявкам `[обязательный, наш акцент]`
- **Смысл:** минимум целевых заявок в договоре, NDA, первые результаты за 14 дней, «всё остаётся при расторжении».

### 12. Отзывы ЛПР + эксперт `[желательный]`
- **Смысл:** отзывы с ролями + карточка руководителя SEO.

### 13. FAQ (8, answer-first) `[обязательный]`
- **Смысл:** стоимость, чем SEO типа отличается, нужен ли блог, сроки, ROI, что входит.
- **Микроразметка:** FAQPage.

### 14. GEO/AI-блок `[обязательный — блок-обгон]`
- **Смысл:** «продвигаем <тип сайта> и в ответы нейросетей».

### 15. Перелинковка на другие типы + связанные услуги `[обязательный]`
- **Смысл:** карточки типов (лендинг/каталог/магазин) + SEO/создание/GEO.

### 16. Финальный CTA — бесплатный аудит `[обязательный]`
- **Смысл:** «покажем точки роста заявок», форма, «ответим за 15 минут».

---

## CTA по странице
- Основной: «Получить бесплатный аудит <тип сайта>».
- Вторичный: «Смотреть тарифы».
- После кейсов: «Хочу заявки из поиска».

## FAQ (смысл ответов)
1. Сколько стоит продвижение <тип сайта>? 2. Чем SEO этого типа отличается от обычного? 3. Нужен ли блог/контент? 4. Через сколько заявки? 5. Как оценить ROI? 6. Что входит в месяц? 7. Работаете ли с Enterprise/крупными? 8. Мультирегион/мультиязык?

## Внутренние ссылки
- → другие типы сайтов, форматы услуг, CMS, ниши, регион.
- → `/geo-prodvizhenie/`, `/sozdanie-sajtov/`, `/cases/`.

## Микроразметка
- `Service`, `FAQPage`, `BreadcrumbList`, `Organization`, `AggregateRating`.

## Функциональные требования
- Тарифные карточки, сравнительная таблица, карточки кейсов «А→B», FAQ-аккордеон, мультиканальная форма, (опц.) квиз.

## Данные от клиента
- Цена/срок и суммы тарифов; счётчики; наши кейсы под тип (метрики); внешние источники для «подтверждено данными»; формулировка гарантии.

## Как адаптировать под другие типы
- Меняются: название типа, боли (магазин→карточки/фильтры; корп→B2B/ЛПР; каталог→ассортимент), направления, кейс-метрики, FAQ. Каркас единый (мастер-шаблон). Для инфо-типов (лендинг, одностраничник, форум, маркетплейс-селлеры) — гибрид «экспертный гайд + блок услуги».

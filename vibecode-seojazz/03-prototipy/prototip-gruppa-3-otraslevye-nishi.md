# Прототип страницы — Группа 3: отраслевая ниша

> Эталонный прототип под нишевую посадочную. Размножается по 100+ нишам (медицина, стройка, e-com, авто, B2B, красота, недвижимость, услуги…). Рабочий пример — `/prodvizhenie-stomatologii/`.
> Два варианта: **A — полный** (конкурентные ниши: стоматология, косметология, стройка, недвижимость) и **B — облегчённый** (низкочастотные ниши с инфо-выдачей). Вход — `02-bloki-analiz/gruppa-3-otraslevye-nishi.md`.
> Обновлено: 2026-07-06.

- **Тип страницы:** нишевая посадочная услуги
- **Интент:** коммерческий (конкурентные) / смешанный-инфо (хвост)
- **Конверсионная цель:** заявка / бесплатный аудит / консультация
- **Первый экран:** польза для ниши + цена «от» + срок + CTA

---

## Вариант A — полный (конкурентные ниши)

### 1. Hero `[обязательный]`
- **Задача:** зацеп под нишу + цена/срок сразу.
- **Смысл:** H1 «SEO-продвижение сайта <ниша>» + подзаголовок «привлекайте больше пациентов/клиентов»; **цена «от …₽»**, средний срок, CTA. `[данные: цена/срок]`
- **SEO-задача:** ключ ниши в H1 и 1-м абзаце.
- **Конв-задача:** CTA «Заказать» + «Бесплатный аудит».

### 2. Контекст ниши `[обязательный]`
- **Задача:** показать понимание рынка ниши.
- **Смысл:** объём рынка/конкуренция в нише + почему органика; тизер нишевого кейса.

### 3. Особенности продвижения ниши + E-E-A-T/YMYL `[обязательный — ключевой]`
- **Задача:** экспертность + доверие (для медицины — YMYL).
- **Смысл:** контент пишут авторы-эксперты/врачи; сертификаты; отзывы; локальное SEO; каталоги (Я.Бизнес/2ГИС); онлайн-запись.
- **SEO-задача:** E-E-A-T-сигналы, тематическая полнота.

### 4. Почему мы + эксперт `[обязательный]`
- **Смысл:** опыт в нише, команда, эксперт-основатель, работа по показателям (стоимость/качество лида, выручка).

### 5. Этапы продвижения `[обязательный]`
- **Смысл:** анализ → техника → контент → ключи → внутр/внеш → локальное SEO → аналитика.

### 6. Тарифы (3, слайдер) `[обязательный]`
- **Смысл:** 3 пакета + состав + «от …₽»; «оплата за результат». `[данные: суммы]`
- **Функционал:** слайдер сравнения.

### 7. Преимущества SEO для ниши `[желательный]`
- **Смысл:** видимость, целевая аудитория, долгосрочность, доверие.

### 8. Нишевые кейсы «А→B» в деньгах `[обязательный]`
- **Задача:** доказать результат из этой же ниши.
- **Смысл:** «точка А → точка B»: заявки/выручка/трафик/ТОП. `[данные: наш кейс по нише — стоматология 24antosplus и др.]`

### 9. Награды/рейтинги `[желательный]`
- **Смысл:** профильные по нише/региону. `[данные]`

### 10. Локальное SEO / каталоги `[обязательный для локальной ниши]`
- **Смысл:** Я.Бизнес, 2ГИС, карты, гео-страницы.

### 11. FAQ `[обязательный — наш плюс, у конкурентов часто нет]`
- **Смысл:** цена, сроки, YMYL/доверие, «подойдёт ли моей клинике». answer-first.
- **Микроразметка:** FAQPage.

### 12. GEO/AI-блок `[обязательный — блок-обгон]`
- **Смысл:** «продвигаем клинику и в ответы нейросетей».

### 13. Форма-квиз + смежные услуги `[обязательный]`
- **Смысл:** мультивопросная форма («узнать стоимость / аудит / консультация») + перелинковка (лендинг, контекст, SERM, личный бренд врача) + Telegram-лид-магнит.

---

## Вариант B — облегчённый (низкочастотные ниши, инфо-выдача)
Сокращённый каркас (там в топе экспертные статьи, а не лендинги):
**Hero (польза+CTA) → экспертный блок «особенности ниши» (развёрнутый, под инфо-интент) → 1 нишевый кейс → мини-тарифы или «от …₽» → FAQ answer-first → GEO/AI-блок → форма.**
Цель — экспертностью и кейсом обойти инфо-выдачу, не раздувая ресурс.

---

## CTA по странице
- Основной: «Рассчитать стоимость для <ниши>».
- Вторичный: «Бесплатный аудит сайта».
- После кейсов: «Хочу такие результаты».

## FAQ (смысл ответов)
1. Сколько стоит продвижение сайта <ниши>? 2. Через сколько результат? 3. Как учитываете E-E-A-T/YMYL (для мед)? 4. Подойдёт ли моей клинике/компании? 5. Работаете ли по локальному SEO/картам? 6. Какие гарантии/по каким показателям?

## Внутренние ссылки
- → отраслевой хаб (`/prodvizhenie-medicinskih-sajtov/` и т.п.) и соседние ниши.
- → `/geo-prodvizhenie/`, `/cases/`, формат услуги (за лиды/за результат), локальная гео-страница.

## Микроразметка
- `Service`, `MedicalBusiness`/`LocalBusiness` (для мед/локальных), `FAQPage`, `BreadcrumbList`, `Organization`, `AggregateRating`.

## Функциональные требования
- Мультивопросная форма/квиз, слайдер тарифов, карточки кейсов «А→B», онлайн-запись/формы, FAQ-аккордеон, Telegram-лид-магнит.

## Данные от клиента
- Цена/срок по нише; суммы тарифов; наш кейс по нише (какой, метрики); авторы-эксперты/врачи для E-E-A-T; награды; какие ниши идут первыми.

## Как адаптировать под другие ниши
- Меняются: название ниши, контекст рынка, особенности (для мед — YMYL/врачи; для стройки — сезонность/гео; для e-com — категории/карточки), нишевый кейс, FAQ, микроразметка (MedicalBusiness vs LocalBusiness). Каркас единый. Конкурентные ниши — вариант A, низкочастотный хвост — вариант B.

# Прототип страницы — Группа 2: GEO/AI (продвижение в нейросеть)

> Эталонный прототип под страницу продвижения в конкретную нейросеть. Размножается по платформам (ChatGPT/Claude/Gemini/Perplexity/DeepSeek/GigaChat/Алиса/AI Overview/Нейро/Grok/Copilot/LLM/AEO). Рабочий пример — `/prodvizhenie-v-otvety-chatgpt/`.
> Каркас (блоки + функция + плейсхолдеры), НЕ финальный текст. Вход — `02-bloki-analiz/gruppa-2-geo-ai.md`.
> Особенность: страница сама строится AI-first (это и есть предмет услуги).
> Обновлено: 2026-07-06.

- **Тип страницы:** посадочная услуги под платформу
- **Интент:** коммерческий, «попасть в ответы <нейросети>»
- **Конверсионная цель:** заявка на бесплатную проверку цитируемости → лид
- **Первый экран:** вопрос-зацеп + метрика рынка AI + 2 CTA (проверка видимости / тарифы)

---

## Структура блоков

### 1. Hero `[обязательный]`
- **Задача:** зацепить болью «вас не цитируют».
- **Смысл:** H1 «Продвижение в ответы <Нейросети>» + подзаголовок-вопрос «когда спрашивают про вашу нишу — <Нейросеть> цитирует вас или конкурента?»; плашка траста в строке (10 лет / 100+ проектов / гарантии в договоре).
- **SEO-задача:** ключ «продвижение в <нейросеть>» в H1 и 1-м абзаце.
- **Конв-задача:** 2 CTA — «Проверить видимость бесплатно» + «Смотреть тарифы».

### 2. Метрики AI-рынка (счётчики) `[обязательный]`
- **Задача:** доказать, что канал реальный и растёт.
- **Смысл:** аудитория нейросети, рост AI-трафика, «3–4 источника в ответе», «2–4 недели до первых цитирований». `[данные: актуальные цифры → источник]`
- **Микроразметка:** —.

### 3. Проблемный блок «почему вас не цитирует» `[обязательный]`
- **Задача:** сформировать потребность + показать экспертизу.
- **Смысл:** 4–5 причин (цитируют конкурентов; контент не под извлечение; низкий DA; нет свежести; нет Schema) + факторы ранжирования с весами (citation frequency 35%, DA 15%, Schema 10%).
- **SEO-задача:** LSI по теме GEO.

### 4. Направления работ (6) `[обязательный]`
- **Задача:** показать, что и как делаем.
- **Смысл:** аудит цитируемости → контент под RAG → citation building → усиление DA/E-E-A-T → техническая GEO (Schema) → мониторинг.

### 5. Сравнительная таблица `[желательный]`
- **Задача:** отстроиться.
- **Смысл:** «мы / обычное SEO-агентство / без GEO» по параметрам (mention rate, мониторинг, промпт-аудит, entities).
- **Функционал:** таблица.

### 6. Кейсы с AI-метриками `[обязательный]`
- **Задача:** доказать результат.
- **Смысл:** citation rate 0%→N%, переходы из нейросети, заявки из AI-канала. `[данные: наши AI-кейсы]`
- **Визуал:** карточки.

### 7. Этапы-таймлайн `[обязательный]`
- **Задача:** ожидания и прозрачность.
- **Смысл:** Дни 1–5 / 5–15 / 15–40 / 45+, у каждого измеримый результат.

### 8. Тарифы (3) `[обязательный]`
- **Задача:** закрыть ценовой интент.
- **Смысл:** Мониторинг / Рост / Лидер — состав + «от …₽/мес» (число нейросетей, промптов, публикаций, SERM). `[данные: наши суммы GEO]`
- **Функционал:** тарифные карточки.

### 9. «Подтверждено данными» `[обязательный — E-E-A-T/обгон]`
- **Задача:** авторитетность (сам блок повышает цитируемость).
- **Смысл:** 3–4 цитаты внешних исследований со ссылками (Similarweb, Princeton GEO, Ahrefs). `[данные: проверить ссылки]`

### 10. Команда + GEO-эксперт `[обязательный]`
- **Задача:** E-E-A-T.
- **Смысл:** руководитель GEO/AI-направления (фото, опыт) + команда.

### 11. Сертификаты / награды `[обязательный]`
- **Смысл:** партнёрства, рейтинги. `[данные: наши награды]`

### 12. Гарантии по citation rate `[обязательный, наш акцент]`
- **Задача:** снять риск.
- **Смысл:** целевой citation rate в договоре, «не достигли — продлеваем бесплатно», «материалы остаются у вас».

### 13. Отзывы ЛПР `[желательный]`
- **Смысл:** отзывы с ролями (CEO, директор по продажам).

### 14. FAQ — большой, answer-first `[обязательный]`
- **Задача:** снять возражения + попасть в саму AI-выдачу.
- **Смысл:** 10+ вопросов (что такое, как выбирает источники, цена, сроки, чем отличается от других нейросетей, локальный бизнес, типы контента, как отследить трафик, гарантии).
- **Микроразметка:** FAQPage.

### 15. Виджет «рейтинг брендов по мнению нейросетей» `[блок-обгон, опциональный]`
- **Задача:** траст + вовлечение (есть только у pixelplus).
- **Смысл:** рейтинги брендов в нишах по версии ИИ.
- **Функционал:** интерактивный виджет. `[решение человека: делаем ли]`

### 16. Связанные GEO-услуги (перелинковка) `[обязательный]`
- **Смысл:** карточки на другие платформы + SEO + SERM + контент-маркетинг.

### 17. Финальный CTA — бесплатная проверка цитируемости `[обязательный]`
- **Смысл:** «проверим ответы по 10 запросам вашей ниши» + форма, «ответим за 15 минут».

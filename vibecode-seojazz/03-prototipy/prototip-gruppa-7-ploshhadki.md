# Прототип страницы — Группа 7: продвижение на площадках

> Эталонные прототипы под площадки. **Два подшаблона:** A — гео-сервисы (Яндекс/Google Карты, 2ГИС, Я.Бизнес, геомаркетинг), B — Авито/маркетплейсы. Референсы — `/prodvizhenie-v-yandex-kartah/`, `/prodvizhenie-na-avito-pod-kljuch/`.
> Вход — `02-bloki-analiz/gruppa-7-ploshhadki.md`.
> Обновлено: 2026-07-06.

- **Конверсионная цель:** заявка / бесплатный аудит присутствия (гео) / расчёт (Авито)
- **Сквозная отстройка:** омниканальность (сайт+SEO+GEO/AI+площадки) и метрики в заявках/выручке

---

## Подшаблон A — гео-сервисы (Карты / 2ГИС / Я.Бизнес / геомаркетинг)

### 1. Hero `[обязательный]`
- **Смысл:** H1 «Продвижение на <площадке>» + подзаголовок «больше клиентов из офлайн через геосервисы»; плашка траста; CTA «Бесплатный аудит присутствия».
- **SEO-задача:** ключ площадки в H1.

### 2. Для кого / для каких задач `[обязательный]`
- **Смысл:** для сетей/филиалов/локального бизнеса; задачи — локальная выдача, конверсия, рейтинг/отзывы, репутация, аналитика.

### 3. Что входит / как помогаем `[обязательный]`
- **Смысл:** управление данными и отзывами → рост трафика из карт → конверсия → генерация отзывов → репутация → аналитика.

### 4. Путь клиента / этапы `[обязательный]`
- **Смысл:** заявка → аудит присутствия → старт → сопровождение/мониторинг.

### 5. Преимущества `[обязательный]`
- **Смысл:** число площадок, официальные интеграции (2ГИС/Я.Бизнес), AI-функции, опыт.

### 6. Отзывы клиентов `[желательный]`
- **Смысл:** отзывы сетей/локального бизнеса.

### 7. FAQ + GEO/AI-блок `[обязательный — наш плюс]`
- **Смысл:** FAQ (что входит, сроки, гео-отзывы, модерация) + связка с сайтом/нейросетями.
- **Микроразметка:** FAQPage, LocalBusiness.

### 8. Лид-магнит «бесплатный аудит присутствия» + форма-квиз `[обязательный]`
- **Смысл:** отчёт о присутствии в геосервисах; квиз (сайт + число филиалов).

---

## Подшаблон B — Авито / маркетплейсы

### 1. Hero `[обязательный]`
- **Смысл:** H1 «Продвижение бизнеса на Авито» + оффер (рост продаж под ключ) + CTA.

### 2. Услуги `[обязательный]`
- **Смысл:** продвижение / упаковка профиля / консультация.

### 3. Тарифы по объёму (3) `[обязательный]`
- **Смысл:** Старт / Профи / Максимум — состав + цена (зависит от объёма объявлений/товаров). `[данные: суммы/объёмы]`
- **Функционал:** тарифные карточки.

### 4. Этапы (9) `[обязательный]`
- **Смысл:** бриф/анализ → договор → стратегия/дорожная карта → запуск (профиль/обложки/тексты/автозагрузка) → ведение + CRM + бот → оптимизация/A-B → отчётность → результаты → масштабирование.

### 5. Команда `[желательный]`
- **Смысл:** спецы по площадкам/маркетплейсам.

### 6. Почему мы + счётчики `[обязательный]`
- **Смысл:** опыт/проекты/результаты.

### 7. Кейсы с метриками `[обязательный]`
- **Смысл:** оборот/ДРР/заказы/CPL. `[данные: кейсы]`

### 8. FAQ + GEO/AI-блок `[обязательный — наш плюс]`
- **Смысл:** FAQ (что входит, сроки, оплата, блокировки/модерация) + омниканальная связка.
- **Микроразметка:** FAQPage.

### 9. Бриф-документ + форма `[обязательный]`
- **Смысл:** скачиваемый бриф + форма заявки.

---

## CTA
- Гео: «Бесплатный аудит присутствия» / «Запросить демо».
- Авито: «Рассчитать стоимость» / «Скачать бриф».

## FAQ (смысл ответов)
- Гео: что входит, сроки, как работаете с отзывами/модерацией, сколько площадок, отчётность.
- Авито: что входит по тарифам, сроки, оплата, как обходите блокировки, интеграция с CRM.

## Внутренние ссылки
- Хаб `/prodvizhenie-na-ploshhadkah/`; между площадками (карты/2ГИС/Я.Бизнес/Авито/геомаркетинг).
- → `/prodvizhenie-sajtov/`, `/geo-prodvizhenie/`, `/cases/` (омниканальность).

## Микроразметка
- `Service`, `FAQPage`, `BreadcrumbList`, `Organization`, `LocalBusiness` (гео).

## Функциональные требования
- Гео: форма-квиз (сайт+филиалы), лид-магнит-отчёт, FAQ-аккордеон.
- Авито: тарифные карточки, аккордеон этапов, скачивание брифа, карточки кейсов, FAQ-аккордеон.

## Данные от клиента
- Гео: как работаем (платформа-партнёр или сами), формат аудита присутствия.
- Авито: суммы/объёмы тарифов, кейсы, бриф-документ.

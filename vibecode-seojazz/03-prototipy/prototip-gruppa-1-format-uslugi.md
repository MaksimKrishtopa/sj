# Прототип страницы — Группа 1: формат услуги SEO

> Эталонный прототип для всех страниц группы «форматы услуг» (по позициям / по трафику / за лиды / за результат / под ключ / сопровождение). Рабочий пример — `/prodvizhenie-s-oplatoj-za-lidy/`.
> Это структурный каркас (блоки + функция + плейсхолдеры), НЕ финальный текст и НЕ дизайн. Вход — `02-bloki-analiz/gruppa-1-formaty-uslug.md`.
> Обновлено: 2026-07-06.

- **Тип страницы:** посадочная услуги (коммерческий лендинг)
- **Интент:** коммерческий, «заказать SEO с оплатой за <модель>»
- **Конверсионная цель:** заявка / бесплатный аудит / расчёт
- **Первый экран (правило):** оффер в языке заявок + доказательство (метрика) + 2 CTA, всё выше линии сгиба

---

## Структура блоков (порядок сверху вниз)

### 1. Hero — первый экран `[обязательный]`
- **Задача:** за 5 секунд объяснить услугу и зацепить оффером.
- **Смысл текста:** H1 «SEO-продвижение сайта с оплатой за лиды» + подзаголовок «платите за заявки и звонки, а не за позиции»; 3 микро-факта (фикс. цена заявки / оплата за результат / рост заявок).
- **Визуал:** фон + иконки-триплет; телефон и город в шапке.
- **SEO-задача:** вхождение ключа в H1 и первый абзац (answer-first).
- **Конв-задача:** 2 CTA — «Рассчитать стоимость» + «Бесплатный SEO-аудит».

### 2. УТП-триплет `[обязательный]`
- **Задача:** снять главное возражение модели оплаты.
- **Смысл:** «фиксированная цена заявки» / «оплата только за результат» / «рост заявок до N раз».
- **Конв-задача:** усилить оффер перед прайсом.

### 3. Кому подходит / кому не подойдёт `[обязательный]`
- **Задача:** квалификация + честность (доверие).
- **Смысл:** списки ниш/условий, где модель «за лиды» работает и где нет.
- **SEO-задача:** вхождение тематических запросов.

### 4. Прайс — тарифы `[обязательный]`
- **Задача:** закрыть ценовой интент открыто.
- **Смысл:** 3 тарифа лесенкой (состав + цена «от …₽»); для «за лиды» — база + оплата за заявку; строка «цена лида по нишам».
- **Визуал:** таблица тарифов + переключатель.
- **Конв-задача:** CTA «Заказать» в каждом тарифе. `[данные от клиента: финальные суммы из tarifnaya-linejka.md]`

### 5. Калькулятор стоимости `[обязательный, наш акцент]`
- **Задача:** вовлечь и дать прогноз в языке заявок.
- **Смысл:** поля — сайт, тематика, трафик, заявки, возраст → прогноз бюджета + прогноз заявок/стоимости лида.
- **Функционал:** интерактивный калькулятор + «отправить расчёт на почту».
- **Конв-задача:** микроконверсия → заявка.

### 6. Сроки и этапы (таймлайн) `[обязательный]`
- **Задача:** сформировать ожидания.
- **Смысл:** 1 / 3 / 6 мес — что происходит; «первые заявки через 3 месяца».

### 7. Что входит / схема работ `[обязательный]`
- **Задача:** показать объём и экспертизу.
- **Смысл:** внутренняя/внешняя/техническая/коммерческие факторы/аналитика — списками, с числами-пруфами.
- **SEO-задача:** тематическая полнота, LSI.

### 8. Кейсы «А→B» `[обязательный]`
- **Задача:** доказать результат в деньгах.
- **Смысл:** 3–6 карточек: клиент + метрики (заявки, трафик, стоимость лида) + ссылка. `[данные от клиента: какие наши кейсы сюда — Эковтор и др.]`
- **Визуал:** карусель.

### 9. Гарантии `[обязательный, наш акцент]`
- **Задача:** снять финансовый риск.
- **Смысл:** финансовая гарантия по KPI-заявкам, зафиксировано в договоре.

### 10. Доверие: команда + счётчики + награды + отзывы `[обязательный]`
- **Задача:** E-E-A-T и доверие.
- **Смысл:** эксперт-руководитель (фото, опыт), счётчики (10 лет, 100+ ниш, 107 650 заявок, 60+ кейсов), отзывы/логотипы. `[данные от клиента: подтвердить цифры]`

### 11. FAQ `[обязательный, answer-first]`
- **Задача:** снять возражения + попасть в AI-выдачу.
- **Смысл:** 5–6 вопросов (см. ниже), прямой ответ первым предложением.
- **Микроразметка:** FAQPage.

### 12. GEO/AI-блок `[обязательный — блок-обгон]`
- **Задача:** отстройка + доп. охват.
- **Смысл:** «продвигаем и в ответы нейросетей» + ссылка на GEO-кластер.

### 13. Формы + лид-магнит `[обязательный]`
- **Задача:** собрать заявку.
- **Смысл:** мультиканальная форма (тел/email/Telegram/Max/WhatsApp) + бонус (бесплатный аудит, чек-листы).

### 14. Перелинковка на смежные форматы `[обязательный]`
- **Задача:** SEO-вес + навигация.
- **Смысл:** карточки «по трафику / по позициям / под ключ / сопровождение» + цена «от».

## CTA по странице
- Основной: «Рассчитать стоимость» (hero, после прайса, после кейсов).
- Вторичный: «Бесплатный SEO-аудит» (hero, в футере блока доверия).
- После FAQ: «Задать вопрос эксперту».

## FAQ (смысл ответов, не финальный текст)
1. Что считается лидом и как вы его фиксируете? → согласуем целевое действие + сквозная аналитика/коллтрекинг.
2. Есть ли фикс-платёж кроме оплаты за лиды? → база + CPA, зачем так.
3. Каким сайтам не подойдёт модель за лиды? → низкий спрос/трафик.
4. Чем «за лиды» отличается от «за трафик»/«за позиции»? → платите за заявку, а не за визиты/места.
5. Через сколько первые заявки? → 3 месяца, стабильно 6+.
6. Какие гарантии? → финансовая по KPI-заявкам в договоре.

## Микроразметка
- `Service` (услуга + provider), `FAQPage`, `BreadcrumbList`, `Organization`, `AggregateRating` (если есть отзывы).

## Функциональные требования (для вайб-кода)
- Калькулятор стоимости (интерактив), таблица тарифов с переключателем, карусель кейсов, FAQ-аккордеон, мультиканальная форма, поповер расчёта на email.

## Данные от клиента (для наполнения)
- Финальные суммы тарифов; цена лида по нишам; какие кейсы выносим; подтверждение цифр-счётчиков; формулировка гарантии; контакты/мессенджеры.

## Как адаптировать под другие страницы группы
- **По трафику/позициям/под ключ/сопровождение:** тот же каркас; меняются оффер в hero, УТП-триплет, состав тарифов, FAQ и кейс-метрики под модель. Калькулятор — под соответствующий прогноз. Перелинковка — на остальные форматы.

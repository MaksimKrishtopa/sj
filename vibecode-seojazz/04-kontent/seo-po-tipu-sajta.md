## 1. Мета-теги
- **Title:** SEO по типу сайта — продвижение под задачу вашего сайта
- **Description:** SEO для интернет-магазинов, лендингов, корпоративных, каталогов, сайтов услуг, визиток и информационных сайтов. Стратегия под тип сайта: заявки и заказы, а не позиции. Бесплатный аудит.
- **H1:** SEO-продвижение по типу сайта: стратегия под задачу вашего сайта

## 2–3. Блоки (вариант B)
- **Hero:** у каждого типа сайта своя механика заявок — магазин продаёт карточками и фильтрами, лендинг одной страницей, каталог ассортиментом. Продвигаем под тип, отвечаем за заявки/заказы. CTA «Подобрать стратегию под мой сайт».
- **Почему тип сайта решает `[ключевой]`:** одинаковое SEO для магазина и визитки не работает — разная семантика, структура, коммерческие факторы, путь к заявке. Сначала определяем тип и его экономику, потом стратегию.
- **Сетка типов (карточки-ссылки) `[ключевой]`:** интернет-магазины (заказы/корзина/чек), лендинги (заявки, гибрид с блогом), корпоративные (B2B/ЛПР, доверие), каталоги (ассортимент без цен, заявки), сайты услуг (заявки/звонки локально), визитки (локальный трафик, минимум страниц), информационные (трафик→монетизация/лиды). Каждая → своя посадочная.
- **Наш подход:** комплекс (техника + контент + AI-SEO/GEO + аналитика), финансовая гарантия по KPI, метрики «А→B» в деньгах, а не строчки в выдаче.
- **Кейсы:** сжатая витрина 2–3 кейса разных типов «А→B» `[illustrative, на согласование]`. → /cases/
- **Мини-тарифы:** Старт 45к · Рост 65к · Бизнес 95к `[на согласование]` → /tariffs/
- **GEO/AI + форма:** /geo-prodvizhenie/. Форма: тип сайта → цель → контакт.
